# odo.moto
🏍️ ODO.MOTO — Diário de Quilometragem  Painel digital para acompanhar os km rodados na moto — pensado como substituto de um painel/odômetro queimado. Registro manual ou automático por GPS, com painel de pilotagem em tela cheia (velocidade + km da rodada + odômetro total), sincronização opcional na nuvem e instalação como app (PWA).
